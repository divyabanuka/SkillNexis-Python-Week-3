## 🧾 Mini Project — Billing System

An OOP-based billing system that demonstrates real-world class design and object interaction.

### Features

- 🛒 Add products
- 💰 Store product name, price and quantity
- 🧮 Calculate product totals
- 📊 Calculate subtotal
- 🧾 Calculate tax
- 💵 Calculate grand total
- 📋 Display final bill in tabular format
- ⚠️ Handle invalid input

### Classes Used

**Product Class**
- Product name
- Price
- Quantity
- Product total calculation

**Bill Class**
- Store products
- Calculate subtotal
- Calculate tax
- Calculate grand total
- Display final bill

**File:** `Mini-Project/Billing-System/billing_system.py`
